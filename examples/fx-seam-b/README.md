**Status:** RED. **ARO alone cannot turn it green**, by design; its green is the INT-2 composition milestone (architect's disposition, 2026-09-10).

## What it reproduces

The failure projection does not touch: the projected `declared` tier for `panel-findings-store` exports `appendFinding`, `getFinding`, `listFindings`; the built `author-agent` imports `getFindings` anyway (`built/manifest.json`). The founding inputs agreed and the build still did not honor them. Loop-side this is the `TS2305` the seam gate catches at plan time (IntegratedAgent `gateway.seam_failures`, `signature_extract.imported_members`; commits `60ea035`, `948e589`, `647e2b0`) and the compiler catches at composition.

The projected exports are **L3** — closures — because the SRS names no read interface for the store (spike/report.md F-14). The check does not care which layer the name came from; the facet is there so an auditor can see it.

## The one check it fails

**Built manifest vs. projected seam**: every symbol a built consumer imports from `panel-findings-store` is among the projected `declared` exports. The check that must make this assertion is the loop's own seam gate, **fed the projected `declared` contract instead of a model-proposed one**. That composition is INT-2 (ARO §11.4). Until it lands the fixture is a joint fixture with no gate to run under, and it stays red.

## What turns it green
