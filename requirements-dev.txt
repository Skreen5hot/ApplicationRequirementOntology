# way it can be: by installing this file into an empty environment and

# what found it.
#
# Pinned exactly rather than with a floor. The point of a pinned file is
# that a clean environment reproduces this one, and ">=" reproduces

#
#   pytest      the suite
#   PyYAML      tools/layout.py reads the layout contract; the licensing
#               tool reads the adjudications

#   rdflib      reading the ontology without a reasoner
#   pyshacl     the SHACL validation ladder
#   owlrl       entailment for the reasoner-scope measurements
#
# rdflib, pyshacl and owlrl are listed now because the ontology checks are
# the next thing to arrive, and a requirements file that describes only
# today's imports has to be edited by whoever adds tomorrow's -- which is
# how it drifts. If a check for them has not landed by the time this is
# reviewed, take them out rather than leaving a pin nothing exercises.
